Belajar GitHub:
Pengalaman Pertama Menghadapi Kendala

Sebuah catatan tentang proses belajar menggunakan Git, GitHub, dan Visual Studio Code.

21 November 2026 Sabtu IT Learning Reading time: 2 min

Hari ini, Sabtu, 21 November 2026, saya bersama tim IT dan pembina IT, Pak Zul, mengalami kegagalan saat mencoba melakukan commit dan push dari Visual Studio Code ke GitHub. Dalam proses pembelajaran ini, ada beberapa kendala yang kami temui.

Kendala yang Dihadapi

  • 1. Aplikasi yang Terhapus Setelah Komputer Restart Salah satu kendala berasal dari komputer di laboratorium TKJ. Setiap kali pengguna atau siswa menginstal aplikasi desktop, seperti Adobe Premiere dan aplikasi lainnya, proses instalasi berhasil dan aplikasi bahkan bisa digunakan selama pembelajaran berlangsung. Namun, setelah komputer di-restart, aplikasi yang sebelumnya diinstal justru hilang.
  • 2. Kendala Saat Pendaftaran Akun GitHub Kendala lainnya terjadi sejak tahap awal, yaitu ketika melakukan pendaftaran akun GitHub. Beberapa kali percobaan pendaftaran mengalami kegagalan. Hal ini diduga berkaitan dengan terlalu seringnya percobaan pendaftaran dari alamat IP yang sama dalam waktu yang sangat singkat, bahkan kurang dari 3 detik.

Catatan Pembelajaran

Dari kejadian hari ini, saya menyadari bahwa belajar Git dan GitHub tidak selalu berjalan lancar. Selain memahami perintah seperti commit dan push, kita juga perlu memahami kondisi perangkat dan jaringan yang digunakan.

Kesimpulan hari ini
Belum berhasil melakukan commit dan push bukan berarti proses belajar berhenti. Pengalaman menghadapi kendala ini menjadi bagian dari pembelajaran saya dalam mengenal GitHub lebih jauh.
